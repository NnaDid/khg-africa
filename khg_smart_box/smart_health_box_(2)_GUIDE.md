## Tools
- 3D printer (PETG capable)
- Soldering iron with fine tip
- Wire strippers and cutters
- Screwdriver set (Phillips, Flat, Security Torx for M4)
- Multimeter
- M2, M3, M4 Hex/Allen keys
- Adjustable wrench or spanner set
- Drill and drill bits (for antenna/cable gland holes)
- Adhesive applicator (for weather seal)

## Assumptions
- Basic soldering proficiency for component connections.
- Familiarity with microcontroller programming environments (e.g., Arduino IDE, PlatformIO).
- Access to a computer with serial communication software for debugging.
- Ability to troubleshoot basic electrical circuits.
- Appropriate power supply for initial testing (e.g., 5-12V DC bench power supply).
